        Разброс модели: сколько раз спросить, прежде чем верить

        Один вызов не отличает свойство файла от разброса модели. Улики снимаются один раз, разбор повторяется. На ранней версии запроса чистый файл однажды получил 0,62 — то есть перешагнул порог. После этого замер стал обязательным:

        Разделение держится на всех вызовах, но запас до порога — сотые доли. В боевой системе решение принимается по медиане нескольких вызовов, а не по одному.

        Чего этот PoC не делает — сказано прямо

        • Правила не видят копию, сохранённую с тем же качеством. Третий файл — участок, скопированный внутри кадра без пересохранения. ELA живёт на разнице в истории сжатия, её там нет, и по правилам балл 28,8 из 100. Подлог там нашла только модель — и в этом весь смысл связки: правила дают воспроизводимое число, модель видит то, подо что правила не написаны.
        • Noise Analysis в балл не идёт. На контрольном прогоне дала ×12.65 на чистом файле против ×12.24 на подделке — то есть не различает. Скриншот остаётся уликой, баллов не даёт.
        • Clone Detection внешнего инструмента не читается машиной и промахивается. Своё «клонов нет» он держит в узле с display:none, разметку поверх картинки не рисует, а на файле, где участок 180×180 скопирован буквально, при трёх наборах порогов копию не показал — зато подсветил солнце. Ту же копию модель на его же скриншоте описала словами.
        • Порог откалиброван на трёх файлах и 15 вызовах модели. Для боевого порога этого мало: на реальном корпусе его надо считать заново вместе с долей ложных тревог.
        • Один из сервисов, названных в задании, отклонён самим агентом — не по вкусу, а по его robots.txt, где закрыт ровно эндпойнт загрузки. Это не обход и не «строгость ради строгости»: на таких запретах строится претензия, и решается это договорённостью или официальным API, а не обходом.
